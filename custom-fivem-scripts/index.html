05 — FAQ

Frequently asked questions

How long does a custom FiveM script take?

It depends on the scope. A simple system and a large interface like a phone or an MDT are very different jobs. Once you tell me what you need, I clarify the scope and give you a clear timeline together with the quote.

How is the price of a custom FiveM script decided?

I don't have a fixed price list; every project is different. The price depends on the script's scope, the interface it needs and the integration work. Just write to me through the form or Discord. Asking for a quote is free.

Which framework do you work with?

My main framework is QBCore, together with common libraries like ox_lib, oxmysql and qb-target. For interfaces I use NUI (HTML/CSS/JavaScript, React when needed).

Is the delivered script encrypted? Do I own the code?

No, it isn't encrypted. I deliver my scripts open-source, so you can read, edit and extend the code however you like.

Can you edit a script I bought?

If the script is unencrypted, yes: I can fix bugs, add features and translate it. Scripts locked with FiveM Escrow can't be opened, so they can't be changed.

I use leaked scripts. Is my server at risk?

Leaked scripts often contain backdoors, which can mean unauthorized access to your server and database. I can scan your resources, find suspicious code and remove it. If the infection is serious, passwords need to be changed and sometimes the server has to be rebuilt, and I'll tell you that upfront.

My server lags a lot. Can you optimize it?

Yes. I find the scripts using high ms in resmon, clean up unnecessary loops and threads, and move work to the server side where possible. We compare the before and after numbers together.

Is hosting included in the FiveM server setup?

The server (a VPS or FiveM hosting) is yours; I handle the installation, QBCore and txAdmin configuration, the database and the integration of the scripts you own. I can also help you choose a hosting provider that fits.

Do you offer support after delivery?

Yes. I install the script on your server and support you until it runs without problems. Extra feature requests later on are discussed separately.
